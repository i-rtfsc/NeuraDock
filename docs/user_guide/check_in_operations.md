# 签到操作

## 手动签到

### 单个账号

1. 在账号页面找到账号卡片
2. 点击**签到**按钮
3. 等待操作完成
4. 查看结果提示通知

### 签到过程

1. **会话检查**：验证缓存的会话是否仍然有效
2. **代理配置**（如启用）：通过配置的代理服务器发送请求
3. **WAF 绕过**（如需要）：启动浏览器绕过 Cloudflare
4. **API 请求**：向服务商发送签到请求
5. **余额更新**：获取并缓存新余额
6. **历史记录**：将签到结果保存到数据库

### v0.5.0 新功能：代理配置

在"偏好设置"页面可以配置应用代理：
- **代理类型**：支持 HTTP、HTTPS 和 SOCKS5
- **代理地址**：格式为 `host:port`，例如 `127.0.0.1:7890`
- **应用范围**：所有签到、余额查询和 Token 获取请求都将通过代理

## 批量签到

一次签到多个账号：

1. 在账号页面，使用复选框选择账号
2. 点击**批量签到**按钮
3. 在对话框中监控进度
4. 完成后查看结果

**提示**：
- 禁用的账号不包含在批量操作中
- 失败的签到不会停止批量操作 - 所有账号都会尝试
- 结果显示每个账号的成功/失败状态

## 自动签到

### 启用自动签到

1. 编辑账号
2. 将**自动签到**切换为启用
3. 设置签到时间（小时和分钟）
4. 按需设置**最小重试间隔**（可选；它只影响失败后的重试节奏）
5. 保存账号

### 调度器会做什么（取决于服务商）

| 服务商类型 | 应用的行为 |
|-----------|-----------|
| 提供签到接口（如 AnyRouter） | 在你设置的时间发起签到请求 |
| 只能在网页签到（如 AgentRouter） | **不发起请求**，改为每 6 小时读取一次余额；发现额度上涨就记一条「推断」的签到记录 |
| 已被标记为不可用 | 不生成任务，也不会每天产生失败日志 |

### 最小重试间隔

- **默认 0**：使用内置的 30 分钟节流
- **可设置 0-24 小时**：失败后再次尝试之间的最短等待
- 它**不再决定"今天能不能签到"**。今天是否已完成由签到记录判定：只要当天已有记录，就不会重复请求
- 连续失败会按指数退避（30 分钟 → 1 小时 → 2 小时 → 4 小时，封顶 6 小时），并且不会跨到下一个签到日

### 自动签到工作原理

- NeuraDock 必须正在运行才能执行自动签到（包括余额轮询）
- 每次尝试都会留下记录：结果、失败原因、耗时，可在「历史」中查看
- 如果应用在计划时间关闭，这次尝试会被跳过；当天仍未完成时，下一次运行会补上
- 同一时刻只会有一个请求在进行（并发触发会被识别为「进行中」而跳过）
- 批量签到进行中可以在界面里取消；取消是协作式的，已经在途的请求会跑完

### 推荐设置

| 设置 | 建议 |
|-----|------|
| 时间 | 清晨（6:00-9:00）以避开高峰时段 |
| 最小重试间隔 | 保持 0（默认节流）即可；只有当你想限制重试频率时才调大 |
| 分散 | 不同账号设置不同时间以避免速率限制 |

## 签到状态

| 状态 | 含义 |
|-----|------|
| 可签到 | 今天还没有记录，且没有请求在进行 |
| 已签到 | 今天已有记录（可能来自服务商确认、推断或手动补记） |
| 进行中 | 该账号的签到请求正在运行 |
| 稍后重试 | 刚才失败了，正在按退避等待；到时间后会自动再试 |
| 已跳过 | 被守卫拦下（例如今天已完成、或已有请求在进行） |

## 常见签到错误

| 错误 | 原因 | 解决方案 |
|-----|------|---------|
| Session expired | Cookies 无效 | 更新 cookies |
| WAF bypass failed | 浏览器自动化失败 | 检查浏览器安装 |
| Network error | 连接问题 | 检查网络 |
| Already checked in | 今天重复签到 | 等到明天 |
| Rate limited | 请求过多 | 等待后重试 |

## 签到历史

查看过去的签到记录：

1. 导航到**签到记录**页面
2. 选择要查看的账号
3. 查看连续签到统计、日历视图和趋势分析
4. 点击日历中的日期查看详细记录

### v0.5.0 签到分析功能

签到记录页面现在提供高级分析：

- **月度概览**：查看本月签到情况、收益统计
- **趋势图**：30天签到和收益趋势可视化
- **日历深度链接**：点击日期跳转到详细记录
- **断签提醒**：自动识别并标记缺失的签到
